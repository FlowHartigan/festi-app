# Visuels du mariage

Ce dossier centralise les fichiers sources fournis pour Once Upon a Fest. Ajouter ici les prochains logos, plans, photos et illustrations, avec des noms descriptifs.

| Fichier | Usage |
| --- | --- |
| `logo-mariage.pdf` | Logo original fourni |
| `plan-mariage.png` | Plan original du festival, auparavant nommé `plan-mariage` sans extension |

Conserver les sources sans modification. Les versions adaptées au web sont placées dans `public/assets` et accessibles dans l'application sous `/assets/`. Le PDF source n'est pas servi aux visiteurs.
