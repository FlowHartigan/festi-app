# Ressources locales

`private/` contient les documents confidentiels utilisés pour préparer le projet,
notamment le classeur des invités et leurs codes d’accès. Ce dossier et tous ses
fichiers sont exclus de Git par `.gitignore`.

Conserver ces documents en local. Ne pas les copier dans `public/`, les intégrer
au frontend, les inclure dans une archive de déploiement ou les envoyer au dépôt.
